FELICIA MISENHEIMER — LIFESTRAW MANAGER, IT & BUSINESS SYSTEMS
FULL BUSINESS SYSTEMS COMMAND CENTER

This candidate-created prototype uses fictional/demo data and is not connected to LifeStraw or a live NetSuite account.

FEATURES
- NetSuite-style order-to-cash lifecycle
- Inventory and replenishment
- Exception queue, event log, controlled retry/recovery
- Integration Control Center for Shopify, Amazon, 3PL, analytics
- Data quality and AI-readiness indicators
- Technology portfolio and cost optimization
- Vendor / MSP scorecard
- NetSuite access governance
- International readiness
- 30/60/90-day ownership roadmap

WINDOWS
1. Unzip this package.
2. Double-click START_DEMO.bat.
3. Keep the black window open.
4. Open http://127.0.0.1:8000

INTERVIEW SEQUENCE
1. Start at KPI / executive view.
2. Create a valid order.
3. Create a unique order with INVALID-123.
4. Show the Exception Queue and Integration Event Log.
5. Click Retry and show recovery.
6. Explain integration health, data quality, vendor/spend controls, access governance, international readiness and 30/60/90 plan.
